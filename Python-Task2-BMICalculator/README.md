# BMI Calculator

## Internship
OASIS INFOBYTE — Python Programming Internship

## Project Description
The BMI Calculator is a beginner-friendly Python application that calculates Body Mass Index (BMI) using weight in kilograms and height in metres. It displays the BMI value and classifies the result into a BMI category.

## Features
- Accepts weight in kilograms.
- Accepts height in metres.
- Calculates BMI using the formula: BMI = Weight / (Height × Height).
- Displays BMI rounded to two decimal places.
- Classifies the result as Underweight, Normal, Overweight, or Obese.
- Handles non-numeric and non-positive inputs.

## Technologies Used
- Python 3
- Python IDLE

## How to Run
1. Open `bmi_calculator.py` in Python IDLE.
2. Select Run → Run Module, or press F5.
3. Enter your weight in kilograms and height in metres.

## Example
Input:
- Weight: 65 kg
- Height: 1.70 m

Output:
- BMI: 22.49
- Category: Normal

## Formula
BMI = Weight (kg) / Height² (m²)
